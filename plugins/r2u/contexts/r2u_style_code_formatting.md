## 指令(做什么)

在本工作区内**新建或修改程序源码**时，采用下列格式化约束；未单独列出的排版细节与 **C++ 标准库（std）** 在规范示例及主流参考实现公开源码中常见的可读风格保持一致。

**适用范围**：以程序语法为主的源文件，常见扩展名包括但不限于：
`*.c`、`*.cpp`、`*.h`、`*.hpp`、`*.cc`、`*.cxx` 等；其他语言若与下述冲突，以该语言社区惯例为准，但仍须满足「空格缩进、行宽」两项硬约束（除非文件已有明确既有风格且用户要求仅局部修改）。

## 约束(怎么做)

### 缩进

- **仅使用空格**，**禁止**用制表符（Tab）作为缩进字符。
- 每一逻辑缩进层级为 **4 个空格**；续行在语义清晰前提下与标准库常见写法一致（可与上一层对齐或按括号悬挂缩进，但须统一、可读）。

### 行宽

- 任一物理行不得超过 **120 个字符**。
- 超长时须在**语义合理**处断行，例如：函数参数列表在逗号后换行、模板实参分层、链式调用在 `.` 或 `->` 前换行、长表达式在二元运算符后换行等。
- **禁止**为凑长度在标识符、字符串字面量、数字字面量或关键 token 中间硬断；必要时先调整结构（临时变量、子表达式抽取）再换行。

### 其余格式（对齐标准库惯例）

包括但不限于下列方面，均参照 std 头文件与规范示例中体现的常见写法（本仓库对 C++ 另有专项规则时，以**更具体且标明适用范围**的规则为准）：

- **大括号**：类、函数、命名空间、控制语句等处的 `{`、`}` 换行与配对方式。
- **空格**：关键字与括号、运算符两侧、模板与尖括号周围、指针/引用声明中的空格习惯等。
- **空行**：逻辑段落之间、声明分组、头文件 include 分段等用于可读性的空行使用。
- **其他**：逗号/分号后空格、初始化列表换行、`namespace` 书写形式等一切未在上文单独列出的排版选择。

## 说明

- 「对齐标准库」指**风格一致**，不要求逐字模仿某一实现；同一仓库内应保持统一。
- 若自动化格式化工具配置与本规则冲突，以本规则为准调整配置或关闭冲突项。
